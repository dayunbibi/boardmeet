# BoardMeet

BoardMeet is a mobile-first web application for planning board game meetups.

Users can create a meetup, share an invite code or link, collect everyone's availability, vote on games, and instantly view the best meeting option.

---

## Features

- Create a meetup
- Join with an invite code or invite link
- Select available dates and time slots
- Vote for board games
- View meetup results
- Mobile-first responsive design

---

## Tech Stack

- Next.js 15 (App Router)
- React
- TypeScript
- Tailwind CSS
- sessionStorage (MVP)

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/boardmeet.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
